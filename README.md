# Quiz Engine

🚧 **Status: Under Development**

**Quiz Engine** is  basic **C-based quiz application** for creating and running multiple-choice quizzes with scoring and file-based data storage.

## About

The project explores fundamental programming concepts by building a simple quiz system capable of handling MCQs, calculating scores, and storing quiz-related data using files.

## Core Idea

* 📝 Multiple-choice questions
* 🎯 Automated scoring
* 📁 File-based data storage
* 💻 Console-based interface
* ⚙️ Basic quiz management
* 🧠 Practice with C programming concepts

## Tech Stack

* C
* File Handling
* Standard C Libraries

## Development

**Quiz Engine** is currently **under development**, with the quiz flow, question handling, scoring system, and file storage functionality being developed and refined.
